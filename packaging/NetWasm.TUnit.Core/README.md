# NetWasm.TUnit.Core

Core TUnit contracts and source-generated test-catalog types for NetWasm test projects.

Install it alongside `NetWasm.TUnit.Assertions` when building a NetWasm test assembly:

```bash
dotnet add package NetWasm.TUnit.Core
```

The package is part of the [TUnit-NetWasm](https://github.com/zion-sati/TUnit-NetWasm) integration and is MIT licensed.
